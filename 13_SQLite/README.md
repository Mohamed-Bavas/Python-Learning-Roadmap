# Day 13 – Database Programming with SQLite 🗄️

## 📌 Overview

On Day 13 of my Python learning journey, I started learning database programming using SQLite. The main goal of this practice session was to understand how Python can work with a database and how the `sqlite3` module helps connect Python programs with SQLite databases.

SQLite is a lightweight database system that stores data in a file. It is useful for learning database concepts and building small Python applications without setting up a separate database server.
