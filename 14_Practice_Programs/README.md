### 2. Fibonacci Series – `fibonacci.py`

Practiced generating the Fibonacci series, in which each number is the sum of the previous two numbers.

**Concepts:**
- Variables
- Loops
- Number sequences
- Updating variable values

### 3. Palindrome – `palindrome.py`

Practiced checking whether a given value is a palindrome. A palindrome reads the same forward and backward, such as `madam`.

**Concepts:**
- Strings
- Conditional statements
- String manipulation or number logic
- Comparison operations

### 4. Prime Number – `prime_number.py`

Practiced checking whether a number is a prime number. A prime number greater than 1 has exactly two positive factors: 1 and itself.

**Concepts:**
- Conditional statements
- Loops
- Arithmetic operators
- Divisibility and remainder
- Logical problem-solving
